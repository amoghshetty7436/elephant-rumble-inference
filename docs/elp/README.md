# ELP rumble detector work

Notes, reports and results from improving FruitPunch's elephant rumble detector for the Elephant Listening Project. The code lives in `tools/` (with tests in `tests/`); this folder holds everything written around it.

| Folder | What |
|---|---|
| `walkthrough/` | Step-by-step explanations, from how the pipeline works to how to run the full rerun (`18-the-full-rerun.md`) |
| `reports/` | Evaluations and comparisons |
| `research_notes/` | Background research (bioacoustics practice, ML methods, post-processing) |
| `results/` | Result pages and the latest improvement run's tables; `aves-finetuning-explained.html` explains fine-tuning and LoRA |
| `retraining-results-2026-10-09/` | First retraining run: logs and the retrained classifier |
| `updates/` | Progress updates |

The ELP datasets and label tables are not in this repository.
